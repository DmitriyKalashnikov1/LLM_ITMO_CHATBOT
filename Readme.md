## Что это?
Это образовательный бот на основе больших языковых моделей (LLM), задача которого помогать студентам лучше усваивать курс по ИИ от Университето ИТМО.

## Как это запустить?
Для запуска данного бота в ОС Ubuntu Linux нужно:

1) Скачать с офф.сайта программу LLM Studio
2) С помощью интерфейса LM Studio скачать модели **qwen/qwen3-vl-4b** и **qwen/qwen3-vl-8b**
2) Запустить в папке бота настройку системы, передав скрипту настройки путь до скаченного файла .appimage (pathToAppImage)
```bash
python -m venv .venv
source .venv/bin/activate
./setupLMStudio pathToAppImage
```
3) После успешного завершения настройки запустить бота нужно командой
```bash
./startLMStudio
```

### Структура проекта

**./dataset/** -- папка с базами данных RAG-системы, а также с набором данных в формате Latex, по которым эти базы данных создавались

**./results/report.csv** -- главный файл отчета об проделанных опытах,

**./results/promptsAndDialogs** -- папка с файлами промптов и диалогов к каждому эксперименту

**./chat.py** -- главный файл кода системы, объединяющий графический интерфейс и логику работы с LLM
